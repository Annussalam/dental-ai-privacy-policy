# Privacy Policy — Dental AI Receptionist

**Last updated: November 21, 2026**

## 1. About This Application

Dental AI Receptionist is an independent demonstration project showcasing an AI-powered WhatsApp chatbot built using n8n and related technologies.

This project is not officially affiliated with, endorsed by, or operated by any dental clinic.

## 2. Information We Process

When users interact with the demonstration, the system may process:

- WhatsApp phone numbers and profile names
- Messages and customer inquiries
- AI-generated responses
- Message timestamps and interaction records

Please do not submit sensitive medical information or confidential personal details.

## 3. How Information Is Used

Information is processed to demonstrate automated customer support, answer general dental-service questions, and test the chatbot's functionality.

## 4. Third-Party Services

The demonstration uses services that may include:

- Meta WhatsApp Business Platform
- n8n for workflow automation
- Google Gemini for AI-generated responses
- Supabase for website knowledge retrieval
- Google Sheets for interaction logging

Information may be processed by these providers as necessary for the demonstration.

## 5. Data Retention and Security

Demonstration interaction records may be stored for testing and troubleshooting. Access is restricted to the project operator.

Data is not intended for sale or advertising purposes. No system can guarantee absolute security.

## 6. Data Deletion Requests

Users may request deletion of their demonstration interaction records by opening an issue in the project's GitHub repository:

https://github.com/Annussalam/dental-ai-privacy-policy/issues

**Do not include phone numbers, message contents, or other personal information in public GitHub issues.** Requests involving personal information should be handled through a private communication channel arranged with the project operator.

## 7. Medical Disclaimer

This demonstration provides general informational responses only. It does not provide medical diagnoses, treatment recommendations, or confirmed appointments.

## 8. Changes to This Policy

This privacy policy may be updated as the demonstration evolves.
